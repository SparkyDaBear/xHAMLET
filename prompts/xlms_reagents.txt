ontology: XLMOD (e.g. XLMOD:00004 for DSS/BS3)
description: The chemical crosslinking reagent used. This is the primary crosslinker

output_format: NT=<name>;AC=<XLMOD or ChEBI accession>;CL=<yes/no>;TA=<residue targets>
  where:
    NT = full chemical name or common abbreviation (e.g. BS3, DSSO, DSS, DSBU, EDC,

    AC = XLMOD or ChEBI accession if identifiable (else null)
    CL = yes if MS-cleavable (DSSO, DSBU, DSBSO, DHSO, BMSO, SDASO, SSD, CBDPS, iQlnk, etc.), no if non-cleavable (BS3, DSS, EDC, PhoX, SDA, PIR, etc.), null if not stated

instructions: Extract explicitly named chemical crosslinkers from the Methods section,
  prioritizing sentences that describe the crosslinking reaction. Never use a generic
  phrase such as "cross-linking reagent" as evidence when the same sentence names the
  reagent (for example, extract DSSO from "DSSO cross-linking reagent").
  ALWAYS populate NT with each reagent name as written in the text, even if the XLMOD
  accession is unknown — set AC=null in that case. Return value=null only after verifying
  that no chemical crosslinker is named anywhere in the provided text.
  If multiple named crosslinkers belong to separate experimental systems and the supplied
  text does not identify which system belongs to this dataset, return a list containing
  every named reagent; do not choose one arbitrarily and do not return null.
  Before responding, verify that a non-null evidence_quote explicitly contains the NT
  value (or its unambiguous expanded chemical name).

  Matching rules against the reference list above:
  - If the text names a reagent that matches one of these entries — by exact name,
    alias, isotope-labeled variant of one of these (e.g. "BS3-d4", "DSS-d12",
    "H12/D12 DSS" are variants of BS3/DSS), or unambiguous expanded chemical name —
    return NT using that entry's name exactly as written above (before any
    parenthetical AC=/targets= annotation), and set AC to that entry's AC value
    unless the text itself states a different accession.
  - If the text names a chemical crosslinking reagent that does NOT match any entry
    in the reference list, still extract it in full (this is how new reagents not yet
    in our database get discovered) — do not force it into a non-matching reference
    entry, and do not omit it. Populate NT/AC/CL/TA with your own best-effort reading
    of the text as usual (AC=null if truly unknown).
  - Do NOT extract reducing/alkylating agents (DTT, iodoacetamide), proximity labeling
    enzymes or their substrates (TurboID, BioID, APEX, biotin-phenol+H2O2), or
    enzymatic/natural crosslinking (e.g. transglutaminase-catalyzed isopeptide bonds)
    as chemical crosslinkers — these are NOT chemical cross-linking reagents.
  - The crosslinker is the specific molecule that physically bridges the two residues
    and contributes its own mass to the detected crosslinked peptide — NOT any other
    reagent merely required to carry out the reaction. Coupling/activating reagents
    (EDC, DMTMM, sulfo-NHS) and quenching reagents (Tris, glycine, ammonium bicarbonate)
    are consumed or washed away without being incorporated into the crosslink, so do
    NOT extract them as a separate crosslinker when a distinct bridging reagent is also
    named in the same reaction. For example, in "a combination of pimelic acid
    dihydrazide (PDH) and the coupling reagent DMTMM", extract only PDH — DMTMM merely
    activates PDH's carboxyl groups and is not itself incorporated. The one exception is
    "zero-length" crosslinking, where EDC or DMTMM is used ALONE (no separate
    hydrazide/amine-reactive bridging reagent named) to directly couple two residues'
    side chains with no added mass bridge; in that case EDC/DMTMM IS the crosslinker.
  - UV-only photo-crosslinking of native residues (no synthetic reagent incorporated)
    has no chemical crosslinker name to extract; return null in that case. This differs
    from photo-reactive reagents that ARE incorporated (diazirine, benzophenone, SDA),
    which should be extracted normally.

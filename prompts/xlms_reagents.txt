term: cross-linker
sdrf_column: comment[cross-linker]
ontology: XLMOD (e.g. XLMOD:00004 for DSS/BS3)
description: The chemical crosslinking reagent used. This is the primary crosslinker
  identifier and must be formatted as a structured key-value string.
output_format: NT=<name>;AC=<XLMOD or ChEBI accession>;CL=<yes/no>;TA=<residue targets>
  where:
    NT = full chemical name or common abbreviation (e.g. BS3, DSSO, DSS, DSBU, EDC,
         formaldehyde, SDA, sulfo-SDA, BMOE, Sulfo-LC-SDA, PIR, CBDPS)
    AC = XLMOD or ChEBI accession if identifiable (else null)
    CL = yes if MS-cleavable (DSSO, DSBU, DSBSO, DHSO, BMSO, SDASO, SSD, CBDPS, iQlnk, etc.), no if non-cleavable (BS3, DSS, EDC, PhoX, SDA, PIR, etc.), null if not stated
    TA = comma-separated reactive residues (e.g. K,nterm or K,S,T,Y or D,E or C)
instructions: Extract explicitly named chemical crosslinkers from the Methods section,
  prioritizing sentences that describe the crosslinking reaction. Never use a generic
  phrase such as "cross-linking reagent" as evidence when the same sentence names the
  reagent (for example, extract DSSO from "DSSO cross-linking reagent").
  ALWAYS populate NT with each reagent name as written in the text, even if the XLMOD
  accession is unknown — set AC=null in that case. Return value=null only after verifying
  that no chemical crosslinker is named anywhere in the provided text.
  If multiple named crosslinkers belong to separate experimental systems and the supplied
  text does not identify which system belongs to this dataset, return a list containing
  every named reagent; do not choose one arbitrarily and do not return null.
  Before responding, verify that a non-null evidence_quote explicitly contains the NT
  value (or its unambiguous expanded chemical name).
  Common cleavable: DSSO (K,S,T,Y; AC=XLMOD:02126), DSBU (K,S,T,Y; AC=XLMOD:02120),
    DSBSO (K,nterm; AC=null), Azide-A-DSBSO (K,nterm; AC=XLMOD:02222), Alkyne-A-DSBSO (K,nterm; AC=XLMOD:02223),
    DSAU (K,nterm; AC=XLMOD:09317), DSPU (K,nterm), DSSBU (K,nterm),
    DHSO (carbonyl-reactive D,E; AC=XLMOD:02226), BMSO (cysteine-specific; C),
    SDASO (K,nterm; photo+MS-cleavable), SDASO-L (K,nterm; photo+MS-cleavable),
    SSD (K,nterm), CBDPS (K,nterm), iQlnk (K,nterm)
  PIR-type enrichable (reporter-ion, NOT backbone MS-cleavable): PIR (K,nterm), BDP-NHP (K,nterm)
  Common non-cleavable: BS3/BS2G (K,nterm; AC=XLMOD:02000/02005), DSS (K,nterm; AC=XLMOD:02001), EDC (D,E,nterm; AC=XLMOD:02010), formaldehyde (K,nterm)

  Photo-crosslinkers (non-cleavable, UV-activated): diazirine (K or incorporated aa), benzophenone (Bpa, pBpa; C or incorporated aa), SDA/sulfo-SDA (K,nterm; AC=XLMOD:02134/02136), aryl azide
  NOTE: Do NOT extract proximity labeling enzymes (TurboID, BioID, APEX, biotin-phenol+H2O2) as crosslinkers — these are NOT chemical cross-linking reagents.

term: quenching reagent
sdrf_column: comment[quenching reagent]
ontology: PRIDE:0000953
description: Reagent used to stop, quench, neutralize, terminate, or consume the crosslinking reaction.
instructions:
  Extract only if explicitly stated in the paper, PRIDE metadata, or cited protocol text.
  Search for synonyms including: quenched, stopped, terminated, neutralized, blocked,
  residual crosslinker, washed with, incubated with, reaction was halted.
Common quenchers:
  - NHS ester crosslinkers such as BS3, DSS, DSSO, DSBU: Tris, ammonium bicarbonate, glycine, lysine
  - Formaldehyde crosslinking: glycine or Tris are common, but only annotate if explicitly stated
For formaldehyde datasets:
  - Inspect the 3–5 sentences after the formaldehyde crosslinking sentence.
  - If the text says "as described previously" or "as described before", and no quencher is named, attempt to read the cited artical and extract the quenching reagent from its methods section.
    If that fall back failes then return value=null with confidence="low" and reasoning="quenching reagent not explicitly stated in provided text; may require cited protocol."
  - Do NOT infer glycine solely because formaldehyde was used.
  - Do NOT treat PBS washes alone as a quenching reagent.
  - Treat Tris-containing lysis buffer as a possible quencher only if the text clearly implies it was use

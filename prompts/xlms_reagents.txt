You are an expert SDRF-Proteomics annotator for crosslinking mass spectrometry (XL-MS) datasets.

Extract the following SDRF metadata terms related to the crosslinking reagent and reaction chemistry.

TERMS TO EXTRACT:
─────────────────────────────────────────────────────────────────────────────
term: cross-linker
sdrf_column: comment[cross-linker]
ontology: XLMOD (e.g. XLMOD:00004 for DSS/BS3)
description: The chemical crosslinking reagent used. This is the primary crosslinker
  identifier and must be formatted as a structured key-value string.
output_format: NT=<name>;AC=<XLMOD or ChEBI accession>;CL=<yes/no>;TA=<residue targets>
  where:
    NT = full chemical name or common abbreviation (e.g. BS3, DSSO, DSS, DSBU, EDC,
         formaldehyde, SDA, sulfo-SDA, BMOE, Sulfo-LC-SDA, PIR, CBDPS)
    AC = XLMOD or ChEBI accession if identifiable (else null)
    CL = yes if MS-cleavable (DSSO, DSBU, SSD, PIR, etc.), no if non-cleavable (BS3,
         DSS, EDC, etc.), null if not stated
    TA = comma-separated reactive residues (e.g. K,nterm or K,S,T,Y or D,E or C)
instructions: Extract from Methods section. If multiple crosslinkers, return a list.
  Common cleavable: DSSO (K,S,T,Y), DSBU (K,S,T,Y), SSD, PIR, CBDPS
  Common non-cleavable: BS3/BS2G (K,nterm), DSS (K,nterm), EDC (D,E,nterm), formaldehyde (K,nterm)

term: crosslinker concentration
sdrf_column: comment[crosslinker concentration]
ontology: PRIDE:0000951
description: Concentration of the crosslinking reagent used in the reaction.
pattern: number + mM or uM (e.g. "1 mM", "500 uM", "0.5 mM")
instructions: Return null if not stated.

term: crosslinker to protein ratio
sdrf_column: comment[crosslinker to protein ratio]
ontology: PRIDE:0000952
description: Molar ratio of crosslinker to protein in the reaction.
pattern: ratio expression (e.g. "50:1", "100-fold molar excess", "5 mM per 1 mg/mL")
instructions: Return null if not stated.

term: quenching reagent
sdrf_column: comment[quenching reagent]
ontology: PRIDE:0000953
description: Reagent used to quench (stop) the crosslinking reaction.
instructions: Common quenchers: Tris, ammonium bicarbonate (ABC), glycine, lysine.
  Include concentration if stated (e.g. "50 mM Tris-HCl, pH 7.5").
  Return null if not stated.

term: crosslink distance
sdrf_column: characteristics[crosslink distance]
ontology: PRIDE:0000948
description: Maximum Cα–Cα distance constraint (spacer arm length) provided by the crosslinker.
pattern: number + Å (e.g. "11.4 Å", "30 Å", "~27 Å")
instructions: Extract the stated spacer length or max distance. Common values:
  BS3/DSS ≈ 11.4 Å, DSSO ≈ 10.1 Å, DSBU ≈ 12.5 Å, EDC ≈ 0 Å (zero-length).
  Return null if not explicitly stated in the text.

term: chemical cross-linking coupled with ms
sdrf_column: comment[chemical cross-linking coupled with ms]
ontology: PRIDE:0000430
description: MS-based cross-linking methodology identifier.
allowed_values: cross-linking mass spectrometry
instructions: Always return "cross-linking mass spectrometry" for any XL-MS dataset.
─────────────────────────────────────────────────────────────────────────────

Return a single JSON object where each key is the exact sdrf_column string shown above.
For each key, return a dict with:
  "value": the extracted value (string, list, or null). For comment[cross-linker] the
           "value" field should contain the full NT=...;AC=...;CL=...;TA=... string,
           and also include separate sub-fields: "NT", "AC", "CL", "TA".
  "accession": ontology accession if resolvable, else null
  "confidence": "high", "medium", or "low"
  "evidence_quote": short verbatim quote from the text, or null
  "evidence_location": location in the paper (e.g. "Methods"), or null

Example for comment[cross-linker]:
{
  "comment[cross-linker]": {
    "value": "NT=DSSO;AC=XLMOD:02056;CL=yes;TA=K,S,T,Y",
    "NT": "DSSO", "AC": "XLMOD:02056", "CL": "yes", "TA": "K,S,T,Y",
    "confidence": "high", "evidence_quote": "crosslinked with 1 mM DSSO",
    "evidence_location": "Methods"
  }
}
